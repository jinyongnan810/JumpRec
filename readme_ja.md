# JumpRec 🪢

> **Apple Watch、AirPods、iPhoneで使える縄跳びワークアウトトラッカー**

*言語: [English](readme.md) | [日本語](readme_ja.md)*

---

**JumpRec**は、Apple Watch、対応イヤホン、またはポケットに入れたiPhoneを使って縄跳びの回数を記録するアプリです。ジャンプ回数、運動時間、心拍数、消費カロリーを記録し、日々のワークアウト履歴を手元で管理できます。

---

## 主な機能

### 🪢 選べる計測方法
- **Apple Watch:** ワークアウト中の手首の動きからジャンプをカウント。
- **AirPods & Beats:** 対応イヤホン（AirPods Pro、AirPods Max、Beats Fit Pro等）のヘッドモーション機能を利用してカウント。
- **iPhone（ポケット）:** iPhoneをポケットに入れて跳ぶだけでも、本体のセンサーでカウント可能。

### ⌚📱 Apple Watch と iPhone の連携
- **リアルタイム表示:** Apple Watchで計測中の内容（ジャンプ数、経過時間、心拍数、カロリー）をiPhone画面にそのまま表示。
- **操作:** どちらのデバイスからでもセッションの終了が可能。

### 🏝️ ライブアクティビティ
- 運動中、ロック画面やDynamic Islandで現在のジャンプ数や経過時間を手軽に確認できます。

### 📊 履歴と記録
- **セッション詳細:** ジャンプ回数、時間、ペース（1分あたりのジャンプ数）、心拍数、推定カロリーを確認。
- **カレンダー表示:** 月別や年別に過去のワークアウトを振り返り。
- **マイルストーン:** 最高ジャンプ数、最長継続時間、最長連続回数などの記録を自動で保存。

### 🗣️ 音声アナウンス
- 100回ごとや1分ごとなど、設定した間隔で回数や時間を端末の音声合成で読み上げ。

### 🎙️ Siri と ショートカット
- Siriやショートカットを使って、直近のワークアウトや今日の合計ジャンプ数を確認したり、セッションを開始できます。
- ワークアウト後の簡単な振り返りテキストも端末内で生成可能。

### 🔒 プライバシー重視
- **アカウント不要:** ユーザー登録やログイン、個人情報の入力は必要ありません。
- **端末内で処理:** センサーデータは端末内でリアルタイムに処理され、外部サーバーに送信されることはありません。
- **iCloud同期:** ワークアウト履歴はユーザー自身のプライベートなiCloud（CloudKit）を介して同期されます。
- **広告・外部トラッカーなし:** サードパーティ製の広告や行動追跡SDKは一切含みません。

### 💰 料金
- **100回まで無料:** すべての機能を最初の100セッションまで無料で使用できます。
- **買い切り型:** サブスクリプション（月額課金）はなく、1度の購入で無制限に利用可能になります。

## 技術構成

| 項目 | 用途 |
| :--- | :--- |
| **SwiftUI & Swift 5** | iOSおよびwatchOSのUI構築 |
| **CoreMotion** | 端末およびイヤホンのモーションセンサーを用いたジャンプ検出 |
| **HealthKit** | ワークアウトセッション管理とAppleヘルスケアへの記録 |
| **SwiftData & CloudKit** | 端末内データ保存とプライベートiCloud同期 |
| **ActivityKit** | ロック画面やDynamic Islandでのライブアクティビティ表示 |
| **AppIntents** | Siriやショートカットアプリとの連携 |
| **StoreKit 2** | アプリ内課金の処理 |

---

## 動作要件

- **iOS 18.0+** / **watchOS 11.0+**
- **ジャンプ検出に対応する機器:**
  - Apple Watch（Series 4以降、Ultra、SE）
  - AirPods Pro、AirPods Max、AirPods（第3世代以降）、Beats Fit Pro
  - iPhone（ポケットに入れて使用）
